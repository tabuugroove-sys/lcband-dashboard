Лиды и Посты · сервер Core

CHG-20260910-003. Проекция только для чтения, без запуска AI и отправки сообщений.

LCB 2.0.app → сервер Core :8880
  Шапка «Бэкенд / данные» → GET /api/core/data-source
    → app-backend-location.json (явное размещение; без догадок по localhost)
    → реальные пути Core и календаря, последние сообщения по каналам, время проверки
    → отсутствие связи показывается отдельно от последнего успешного результата
  Смена автономности → свежий Core health → штатный session/challenge при native auth
    → существующие runtime и transport gates остаются обязательными
  GET /api/app/lead_flow
    → lead-review-selection.json (ссылки и примечания отчёта)
    → core.db / messages (полный актуальный исходник)
    → подборка обращений; не подтверждение карточки или доставки
  GET /api/app/posts_live
    → core.db / messages (публичные каналы, выбранное окно)
    → свежая лента; категория и доставка не предполагаются
  Чаты → папка «Карта лидов» → GET /api/app/lead_chats
    → контакты из той же подборки → точные channel/account/identity → личные threads
    → реальная переписка через штатный /api/core/messages
    → отсутствующий или неоднозначный диалог: заявка и явный статус, без создания треда

Нет файла подборки → прежний локальный proxy :8878
Неверный файл или недоступная база → явная ошибка, без старого снимка
Календарь → прежний calendar-mirror.db (этим изменением не обновляется)

Сопоставление: channel + peer_external_id + provider_message_id; при нескольких account_id требуется сверка. Все SQLite-соединения mode=ro, query_only; новые команды, сделки и исходящие не создаются.
