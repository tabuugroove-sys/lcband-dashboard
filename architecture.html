Telegram user-account delivery boundary
Business agent → reviewed immutable envelope → explicit approval → telegram_delivery_queue.py · tg_delivery.sqlite → com.lcband.telegram-delivery → Telegram
Бизнес-агенты не имеют transport-capability. Единственный физический Telethon writer — telegram_delivery_service.py. Approval одноразовый и привязан к exact subject/recipient/payload; queued != delivered, а attempt без provider receipt становится unknown без слепого auto-retry. Bot API notification/control использует отдельную bot identity.
