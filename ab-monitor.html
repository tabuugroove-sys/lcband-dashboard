📊 Анализ

✅ TG Push Monitor

  • Real-time реакция — пост пришёл → за секунды
  • Не зависит от Chrome / сессии браузера
  • Читает полный текст через Telethon API
  • Без лимитов на скорость прокрутки
  • Heartbeat catch-up каждые 30 мин
  • Работает 24/7 без участия пользователя

⚠️ Browser Walk

  • Видит то, что видит человек — включая закреплённые/отложенные
  • Может читать закрытые чаты (где API не работает)
  • Зависит от Chrome + TG Web сессии
  • Медленнее (~5-10 мин на 18 чатов)
  • Ломается при смене интерфейса TG Web
  • С мая 13 не запускается (script_exit_rc=0)
