Проверка

Новый Core работает отдельно

Приложение читает каноническую Core DB без legacy fallback. Отдельный shadow-writer записывает только черновики; он не меняет unread и не имеет доступа к транспортам мессенджеров.

Данные

Предохранители

  • ×Нет read fallbackКонтакты и сообщения читаются из Core.
  • ✓Черновик не является отправкойShadow-writer создаёт immutable draft без outbound intent и без messenger SDK.
  • ✓Ручная отправка отделенаТолько точный текст оператора через единственного delivery-owner и provider receipt.
  • ×Автоответы выключеныАгенты остаются в SEND HOLD.
