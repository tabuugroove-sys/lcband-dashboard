Кейс-эталон: Лофт Холл #2 (Катя 28.04) — «они на эксклюзиве, ваш не пускают» → играем на их аппарате, бэклайн = 0 в нашем чеке, гонорар 200к БН чистый.

Без распознавания этого сигнала — двойная ошибка:
• Сказали 200к + 50к бэклайн на эксклюзивную площадку → клиент платит за то что не нужно, мы дорогие.
• Сказали 200к без бэклайна на outdoor → 50к недополучили.

💼 Юр. канал — Кирилл 12% (НЕ на каждый event)

ИП Щукин Кирилл Андреевич = наш юр. канал для БН-платежей. Кирилл забирает 12% от полной суммы БН-чека (включает УСН-налог + его маржу как владельца ИП).

🚨 12% применяются ТОЛЬКО когда деньги идут через БН. Из контекста определи нал vs БН до того как считать маржу.
Сценарий оплатыКирилл 12%Почему
Нал прямой клиент, без посредника (физлицо, свадьба своя, ДР)0деньги мимо ИП, мимо Кирилла
Нал через посредника / event-агентство0 от нашего чекаагент работает с клиентом, к нам приходит нал
БН прямой юр. клиент (ООО / АО / ИП)−12% от БНпроходит через ИП Щукин
БН через event-агентство (АК есть)−12% от БНтоже через ИП Щукин
Смешанная оплата (часть нал, часть БН)−12% только от БН-частитолько БН-поток через ИП

🚨 АК (агентская комиссия) — обычно НЕ наш расход

Стоимость договора = чистая сумма, что приходит к нам. Если клиент работает через агента (event-агентство) — агент берёт свой % у клиента до того как договор приходит к нам. В нашем договоре стоит уже чистая сумма. АК НЕ вычитается из нашего чека повторно.

Эталон: Лофт Холл #2 — Катя 04.05 [051] пишет: «это уже минус комиссия». В договоре с УАН ОНЛИ стоит 200к → нам приходит 200к чистыми. АК в нашем расчёте = 0.

📐 Логика применения (порядок проверок)

1. DECLINE-сигнал есть? → skip
2. Welcome / solo / duet формат? → новая шкала (НЕ base ×N)
3. Зарубеж? → $3000/чел/мес матрица отдельно
4. UP-сигнал? → base × multiplier (макс. суммарный +50%)
5. DOWN-сигнал? → base или −10%
6. Бэклайн — отдельный slot, спросить если неясно
7. По умолчанию → base из шкалы 4-7 чел
